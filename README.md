# 🎵 Spotify Web Player - Responsive Single Page Application (SPA)

A modern, responsive, feature-packed Single Page Music Streaming Web Application built using **HTML5 / DHTML**, **CSS3**, **Bootstrap 5**, and **Vanilla JavaScript (ES6+)**.

---

## 🌟 Key Features & Requirements Breakdown

### 1. HTML5 / DHTML Structure
- **Semantic HTML5 Tags**: `<header>`, `<nav>`, `<aside>`, `<main>`, `<section>`, `<article>`, `<canvas>`, `<footer>`.
- **Dynamic HTML (DHTML)**: Real-time DOM manipulation for song catalog filtering, interactive audio visualizer, dynamic playlist generation, synced live lyrics, and toast alerts.

### 2. CSS3 Custom Styling
- **Spotify Dark Theme Design System**: Built with modern dark aesthetics (`#121212`, `#181818`, `#1db954` Spotify Green).
- **Glassmorphism & Micro-animations**: Glass backdrop filters, smooth hover elevates, glowing accents, and custom scrollbars.
- **Responsive Layout**: Designed mobile-first, tablet, and desktop adaptive layouts.

### 3. Bootstrap 5.3 Framework & Components
This project implements **multiple Bootstrap components and features**:
- 📱 **Bootstrap Grid System**: Responsive layout using `container-fluid`, `row`, `col-12 col-sm-6 col-md-4 col-lg-3 col-xl-2`, and `g-3` / `g-4` gutters.
- 🧭 **Bootstrap Navbar & Offcanvas Sidebar**: Seamless responsive navigation with desktop sidebar and mobile offcanvas navigation drawer.
- 🎠 **Bootstrap Carousel**: Featured artist, trending album, and podcast spotlight banner with controls and indicators.
- 🗂️ **Bootstrap Nav Pills & Tabs**: Dynamic category filtering (All, Pop, Rock, Hip-Hop, Lo-Fi, Electronic, Podcasts).
- 📦 **Bootstrap Modals**:
  - *Create Playlist Modal* with dynamic form input.
  - *Synchronized Lyrics & Song Details Fullscreen Modal*.
  - *Premium Subscription & Checkout Modal*.
  - *User Profile & Audio Quality Settings Modal*.
- ❓ **Bootstrap Accordion**: FAQ section for streaming questions, offline mode, and student discounts.
- 🍞 **Bootstrap Toast Notifications**: Interactive alerts for liking songs, creating playlists, following artists, and newsletter subscriptions.
- 🏷️ **Bootstrap Badges, Progress Bars & Dropdowns**: Status badges, interactive audio progress scrubber, notification dropdown, and profile menus.

### 4. Interactive Music Playback & Audio Engine
- **Synthesizer & Audio Engine**: Built with Web Audio API sound synthesis and interactive playback timer.
- **Full Player Bar**: Play / Pause, Next / Previous track, Shuffle, Repeat, Seek scrub bar, Volume slider, and Mute toggle.
- **Canvas Audio Visualizer**: 3 selectable visualizer modes (Equalizer Bars, Sine Waveform, Neon Pulse).
- **Live Search**: Instant real-time filtering across songs, artists, albums, and genres.
- **Keyboard Shortcuts**: `Space` (Play/Pause), `Shift + Right/Left Arrow` (Next/Prev), `M` (Mute/Unmute).

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Using Python Simple HTTP Server
python3 -m http.server 8080

# Using Node.js npx serve
npx serve .
```
